# MCR-Former

Code for the manuscript

> **Minimal Complete Representations Enable Data-Efficient Learning of Periodic Physical Sequences in Composite Laminate Design**
> Rui Li, Qiang Huang, James Lin, Jiayin Liu, Yin Fan\*, Minhua Wen\* — submitted to *Communications Engineering*.

The data- and code-availability statements of the manuscript point to this repository
(<https://github.com/lrwlx/MCR_Former>). It contains the model implementation, the
data-generation scripts (Classical Lamination Theory), the training and evaluation scripts,
the ablation and transfer-learning studies, the inverse-design search and the figure scripts
behind every table and figure of the paper and its Supplementary Information.

Every script uses paths relative to its own folder, so the repository can be cloned anywhere. Run each script from the folder that contains it.

## Environment

```bash
python -m pip install -r requirements.txt
```

Tested with Python 3.13 and PyTorch 2.10 (CPU is sufficient: the model has about 2.5 × 10^5 trainable parameters in the ablation configuration and 4.1 × 10^5 in the flagship configuration; see Methods 4.3 of the manuscript). A GPU is supported but not required.

## Reporting note — two model configurations (read this before comparing numbers)

The manuscript reports two model configurations, which is why absolute accuracies differ between tables. Both are produced by this repository:

| Configuration | Used by | Architecture | Run |
| --- | --- | --- | --- |
| Flagship protocol | Table 1, Fig. 2 | 3 encoder layers, 2 heads, d_model 64, d_ff 512, dropout 0.09, 60 epochs, 80/20 split of the 3,000-sequence 16-ply dataset | single run, seed 42 (`experiments/v13_main/`); `experiments/v13_main/five_seed/` repeats it over seeds 42-46 |
| Ablation configuration | Table 2, Table S1, Fig. 3 | 4 encoder layers, 8 heads, d_model 64, d_ff 256, dropout 0.1, 80 epochs | seed 42 for the encoding sweep; the reversal-invariance study is repeated over five seeds |
| Per-thickness surrogates | Table 5 | small MCR-Former trained per target thickness (see each `train_evaluate_v13.py` config) | seed 42 |

Table 1: all rows were produced in this work on the same 3,000-sequence dataset and the same 2,400/600 train-test split; each baseline uses its own native input representation. The citations in the manuscript identify the architectures, not the source of the numbers.

## Datasets

All datasets in this repository were generated by Classical Lamination Theory from Sobol-sampled ply angles; no experimental data are included.

| Dataset | File | Size |
| --- | --- | --- |
| 16-ply flagship / ablation | `experiments/v13_main/composite_v13_dataset.csv`, `experiments/encoding_ablation/composite_v13_dataset.csv`, `experiments/external_baselines/composite_v13_dataset.csv` (identical copies) | 3,000 sequences |
| Per-thickness pools (variable length) | `experiments/cross_scale/data/layer_<N>.csv` | 500 sequences per thickness |
| Per-thickness pools (transfer) | `experiments/few_shot/data/layer_<N>.csv` | 200 sequences per thickness |
| Cross-property target (nu12) | `experiments/cross_property/data_v12/v12_dataset.csv` | 500 sequences |
| Per-thickness surrogate datasets | `experiments/inverse_design/<size>Layer/composite_v13_dataset_<size>.csv` | 2,000 / 10,000 sequences |

`get_v.py` / `get_v13.py` in the experiment folders implement the underlying CLT relations and rebuild any dataset from the sampling strategy described in Methods 4.1.

## Reproducibility notes

- Seeds are fixed inside every script (`random_state` / `set_seed`). The flagship script keeps the seed in its config; the five-seed repeat takes `--seed` on the command line.
- Trained weights (`*.pth`) are not tracked by git. Scripts that fine-tune a base model or run the inverse design expect the base model to be trained first; each folder README states the exact chain.
- Raw result archives for the transfer-learning runs (`experiments/few_shot`, `experiments/cross_property`) are regenerated by the scripts (they write to `results_few_shot_analysis/` and `results_v12/`); the archived numbers quoted in the manuscript are the ones tabulated in the figures and in `figures/Fig5/Fig5.py`.
- Figures 2, 4 and 5 are plotted from the CSV files stored next to the plotting scripts; Fig. 3 carries its matrix inline; Fig. 5 carries the tabulated transfer values inline.
- Small numerical differences from the manuscript are possible across library versions or hardware; the archived result files in each folder are the reference outputs of this repository.

## Running on a cluster

`CLUSTER.md` describes how to run the two revision experiments (five-seed repeat and per-thickness baseline) on a Linux server, and `run_all_h100.sh` automates it.
